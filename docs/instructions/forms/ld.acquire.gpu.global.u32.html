9.7.10.8 · Restricted core model

ld.acquire.gpu.global.u32

An acquire read can take part in synchronization with a qualifying release. Its observed value and resulting ordering are checked by the memory graph; seeing a flag is not assumed to make data current.

Model restrictions

Restricted global-memory message-passing model: aligned non-overlapping words, GPU scope, ordinary memory-access mechanism, and finite straight-line programs. The basic store syntax uses internal literal values rather than actual PTX register syntax. It is not a complete PTX parser or unrestricted dependent-concurrency model.

This page documents an existing bounded formalization. It is not promoted to the independently accepted instruction-form ledger. Read its module comments and proof hypotheses for the precise execution restrictions.

Lean definitions

Ptx.Instr.step · opening excerpt; follow the link for full source

def Instr.step (instruction : Instr) (registers : Registers) (readValue : Word) :
    Registers × Effect :=
  match instruction with
  | .load order address destination =>
      (fun register => if register = destination then readValue else registers register,
       ⟨.load order, address, readValue⟩)
  | .store order address value =>
      (registers, ⟨.store order, address, value⟩)
