9.7.1.14 · Reviewed form

max.s32

Compare two 32-bit words as signed numbers from −2^31 through 2^31−1, using two’s-complement encoding. Copy the larger value into the destination register. Equal inputs give that same value.

The signed form treats a set highest bit as part of a negative number; the unsigned form does not. Every input bit pattern is allowed.

Model restrictions

Typed pure32-family leaf over supplied scalar states; word sources and one word destination, positive predicate selector for selp. No raw text/declaration checking, other widths, packed/saturation forms, complete kernel or hardware claim. Exact ISA94/SM>=10 feature requirement on fetched Step, not recognized-target validation.

Operands and execution

Destination
compatible 32-bit word register

Guard

Version
Introduced in PTX 1.0; selected ISA 9.4
Target
sm_10 feature floor; not recognized-target validation

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.

Lean definitions

Ptx.Scalar.SignedMinMax32.compute · opening excerpt; follow the link for full source

def compute (op : Operation) (a b : Word) : Word :=
  match op with
  | .min => if a.toInt < b.toInt then a else b
  | .max => if a.toInt > b.toInt then a else b
