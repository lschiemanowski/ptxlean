9.7.10.7 · Reviewed form

prmt.b32

Build four output bytes by selecting from the eight bytes of two input words. A byte is eight bits. Input bytes 0–3 come from the first word and 4–7 from the second, with each word numbered from its least significant byte.

Each output byte has a four-bit selector in the low half of the control word. Three selector bits choose an input byte. The fourth chooses whether to copy it or fill the output byte with eight copies of its highest bit. The upper sixteen control bits are ignored, and the control may be a register or an immediate word.

Model restrictions

Plain prmt.b32 only, ISA 94 and numeric SM >= 20. No specialized modes, raw-module/declaration validation or hardware correspondence.

Operands and execution

Destination
compatible 32-bit word register
Sources
compatible declared 32-bit first source or already converted immediate; compatible declared 32-bit second source or already converted immediate; compatible declared 32-bit control register or already converted immediate; all bit patterns admitted, low sixteen bits used
Overlap
Incoming source values; unrestricted source/destination overlap and repeated operands.
Guard
Unconditional, positive or negative predicate; skipped execution advances PC and emits guard-only read metadata.
Version
Introduced in PTX 2.0; selected ISA 9.4
Target
sm_20 feature floor; not recognized-target validation

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.

def compute (_op : Operation) (a b c : Word) : Word :=
  (BitVec.ofBoolListLE (List.ofFn fun i : Fin 32 =>
    let selector := (c.toNat / 2 ^ (4 * (i.val / 8))) % 16
    let source := if selector % 8 < 4 then a else b
    source.getLsbD (8 * (selector % 4) + (if 8 ≤ selector then 7 else i.val % 8)))).cast (by simp)
