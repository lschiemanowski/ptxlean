9.7.10.11 · Restricted core model

st.relaxed.cta.shared.u32

Write a 32-bit register word into memory shared within a thread block; each thread writes its own slot before the common barrier.

Model restrictions

A CTA is a launched thread block. This fragment has fixed full participation, no early exit, one barrier visit, resource zero, and initialized aligned shared storage with explicit ownership and size bounds. It does not cover arbitrary barrier counts, divergence, general reuse, raw PTX parsing or scheduling fairness.

This page documents an existing bounded formalization. It is not promoted to the independently accepted instruction-form ledger. Read its module comments and proof hypotheses for the precise execution restrictions.
