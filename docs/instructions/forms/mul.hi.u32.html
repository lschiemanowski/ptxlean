9.7.1.3 · Reviewed form

mul.hi.u32

Multiply two 32-bit words interpreted as unsigned integers. Represent the full product in 64 bits, then return its upper 32 bits, discarding the lower half.

The result is exact for this integer operation. No floating-point rounding or saturation is involved.

Model restrictions

Typed Pure32 family selecting mul.hi.u32, mul.hi.s32; ISA 94 and numeric SM >= 10. No other widths/options, module parser, declared-register checking, whole-kernel or hardware claim.

Operands and execution

compatible 32-bit word register

Version
Introduced in PTX 1.0; selected ISA 9.4
Target
sm_10 feature floor; not recognized-target validation

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.

Lean definitions

Ptx.Scalar.MulHi32.compute · opening excerpt; follow the link for full source

def compute (op : Operation) (a b : Word) : Word :=
  match op with
  | .unsigned => BitVec.ofNat 32 ((a.toNat * b.toNat) / 2^32)
  | .signed => BitVec.ofInt 32 ((a.toInt * b.toInt) / (2^32 : Int))
