9.7.9.6 · Reviewed form

lop3.b32

Combine three 32-bit inputs using a supplied truth table: a list of the output bit for each of the eight possible triples of input bits. Apply that same rule independently at all 32 positions.

The first input contributes 4 to the table index, the second 2, and the third 1 when its bit is set. The table is an immediate integer from 0 to 255, supplied in the instruction rather than read from a runtime register.

Model restrictions

Plain lop3.b32 only, ISA 94 and numeric SM >= 50. No BoolOp predicate result or sink destination, raw module/declaration validation or hardware correspondence.

Operands and execution

Destination
compatible 32-bit word register
Sources
compatible declared 32-bit word register or already converted immediate; compatible declared 32-bit word register or already converted immediate; compatible declared 32-bit word register or already converted immediate
Overlap
Incoming source values; unrestricted source/destination overlap and repeated operands.
Guard
Unconditional, positive or negative predicate; skipped execution advances PC and emits guard-only read metadata.
Version
Introduced in PTX 4.3; selected ISA 9.4
Target
sm_50 feature floor; not recognized-target validation

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.

Lean definitions

Ptx.Scalar.Lop3.compute · opening excerpt; follow the link for full source

def compute (op : Operation) (a b c : Word) : Word :=
  let na := ~~~a
  let nb := ~~~b
  let nc := ~~~c
  (if op.getLsbD 0 then na &&& nb &&& nc else 0) |||
  (if op.getLsbD 1 then na &&& nb &&& c else 0) |||
  (if op.getLsbD 2 then na &&& b &&& nc else 0) |||
  (if op.getLsbD 3 then na &&& b &&& c else 0) |||
  (if op.getLsbD 4 then a &&& nb &&& nc else 0) |||
  (if op.getLsbD 5 then a &&& nb &&& c else 0) |||
  (if op.getLsbD 6 then a &&& b &&& nc else 0) |||
  (if op.getLsbD 7 then a &&& b &&& c else 0)
