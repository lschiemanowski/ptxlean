9.7.1.20 · Reviewed form

bfe.s32

Extract a consecutive group of bits, starting at a position counted from the least significant bit, and place it at the low end of the result. Extend it to a 32-bit signed value by repeating its sign bit in the higher positions.

Only the low eight bits of the position and length operands are used. For a field that reaches past the input, the input’s highest bit supplies the sign. A position past bit 31 can therefore give all ones for a negative input. A zero length always gives zero.

Model restrictions

Typed Pure32 family selecting bfe.u32, bfe.s32; ISA 94 and numeric SM >= 20. No other widths/options, module parser, declared-register checking, whole-kernel or hardware claim.

Operands and execution

Destination
compatible 32-bit word register
Sources
compatible declared 32-bit word register or already converted immediate; unsigned 32-bit position (low eight bits used); unsigned 32-bit length (low eight bits used)
Overlap
Incoming source values; unrestricted source/destination overlap and repeated operands.
Guard
Unconditional, positive or negative predicate; skipped execution advances PC and emits guard-only read metadata.
Version
Introduced in PTX 2.0; selected ISA 9.4
Target
sm_20 feature floor; not recognized-target validation

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.

Lean definitions

Ptx.Scalar.Bfe32.compute · opening excerpt; follow the link for full source

def compute (op : Operation) (a b c : Word) : Word :=
  let pos := b.toNat % 256
  let len := c.toNat % 256
  let sign := match op with
    | .unsigned => false
    | .signed => len != 0 && a.getLsbD (min (pos + len - 1) 31)
  BitVec.ofNat 32 ((List.range 32).foldl (fun acc i =>
    if (if i < len && pos + i < 32 then a.getLsbD (pos + i) else sign)
    then acc + 2^i else acc) 0)
