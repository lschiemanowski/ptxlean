9.7.1.15 · Reviewed form

popc.b32

Count how many of the input word’s 32 bits are one. The result ranges from zero, for an all-zero word, to 32, for an all-one word.

Model restrictions

Typed operand interface only, not raw PTX parsing or register-declaration validation; version/target facts are not enforced by this arithmetic decoder. Exact values, not floating-point approximation or hardware conformance.

Operands and execution

Destination
u32 word register
Sources
b32 word register or 32-bit immediate
Overlap
Sources read from incoming state before destination write; source/destination overlap permitted.
Guard
Unconditional, positive predicate, or negated predicate. False guard skips the write and advances the program counter.
Version
Introduced in PTX 2.0; this decoder does not enforce version/target eligibility
Target
sm_20

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.

def UnaryOp.eval : UnaryOp → Word → Word
  | .clz, a => BitVec.ofNat 32 ((List.range 32).reverse.takeWhile
      (fun i => !a.getLsbD i)).length
  | .popc, a => BitVec.ofNat 32 ((List.range 32).filter
      (fun i => a.getLsbD i)).length
