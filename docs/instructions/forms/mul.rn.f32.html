9.7.3.5 · Reviewed form

mul.rn.f32

Interpret two input words as binary32 numbers, the usual 32-bit single-precision floating-point format, and compute their product. Round to the nearest representable value; an exact tie chooses the value whose last retained significand bit is even.

Very small representable values, called subnormal numbers, are preserved rather than replaced with zero. For results that are not NaN (a special “not a number” encoding), the model fixes the reference result bits, including the sign of zero. When the reference produces NaN, the model allows any NaN encoding to preserve unspecified payload bits. This conservative allowance does not claim that hardware can produce every such encoding.

Model restrictions

Typed FP-only fetched leaf over supplied state, not raw PTX parsing, declaration checking, integer-to-float conversion, recognized-target validation, complete kernel execution, hardware or PyTorch conformance. Exact ISA94/SM>=20 feature condition checked on Step. No FTZ, saturation, other rounding, packed or f64 forms.

Operands and execution

Destination
compatible b32/f32 word register
Sources
compatible b32/f32 word register or already-decoded exact 0f/0F bit literal; compatible b32/f32 word register or already-decoded exact 0f/0F bit literal
Overlap
Every source is read from the incoming state; source/destination overlap is unrestricted.
Guard
Unconditional, positive predicate or negated predicate; false guard preserves all data and advances PC, with guard-only read metadata.
Version
Introduced in PTX 1.0; selected ISA 9.4
Target
sm_20 for selected gradual-underflow semantics

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.
