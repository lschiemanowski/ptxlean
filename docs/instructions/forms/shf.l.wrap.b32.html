9.7.9.7 · Reviewed form

shf.l.wrap.b32

Join two 32-bit words into a 64-bit value: the first input is the low half, and the second is the high half. Shift that value left, fill vacated positions with zeros, and return the high 32 bits.

The count is an unsigned 32-bit word. Use its remainder after division by 32, so count 32 acts like zero and count 33 acts like one. Supplying the same word as both sources rotates that word’s bits.

Model restrictions

Four exact b32 funnel-shift spellings, ISA94 and numeric SM >=32. No raw module/declaration or target-name validation, no hardware correspondence.

Operands and execution

Destination
compatible 32-bit word register
Sources
compatible declared 32-bit low source or already converted immediate; compatible declared 32-bit high source or already converted immediate; unsigned 32-bit runtime count, register or already converted immediate; every bit pattern admitted
Overlap
Incoming source values; unrestricted source/destination overlap and repeated operands.
Guard
Unconditional, positive or negative predicate; skipped execution advances PC and emits guard-only read metadata.
Version
Introduced in PTX 3.1; selected ISA 9.4
Target
sm_32 feature floor; not target-name validation

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.

Lean definitions

Ptx.Scalar.Shf32.compute · opening excerpt; follow the link for full source

def compute (op : Operation) (a b c : Word) : Word :=
  let n := match op with
    | .leftClamp | .rightClamp => min c.toNat 32
    | .leftWrap | .rightWrap => c.toNat % 32
  match op with
  | .leftClamp | .leftWrap => (b <<< n) ||| (a >>> (32 - n))
  | .rightClamp | .rightWrap => (b <<< (32 - n)) ||| (a >>> n)
