9.7.3.13 · Reviewed form

rcp.rn.f32

This form takes one binary32 operand (the standard 32-bit floating-point format) and writes its reciprocal, one divided by that value. The result is rounded to the nearest representable value; halfway cases select the result with an even final significand bit. Small subnormal values are retained rather than flushed to zero.

The model includes signed zeros and infinities: a zero input produces infinity with the same sign, and an infinite input produces a zero with the same sign. A NaN input, meaning not a number, produces a NaN with the existing conservative allowance for unspecified bit patterns. Finite inputs can still overflow on reciprocal, so execution itself has no finite-output premise.

A true predicate executes using the original operand, including when source and destination use the same register. A false predicate skips the arithmetic and preserves data. Fetched execution checks PTX ISA 9.4 and a numeric target level of at least sm_20. The typed decoder handles this exact spelling, not the approximate variant, other rounding modes, flush-to-zero or 64-bit floating-point forms. This leaf is not a complete kernel or a hardware conformance result.

Model restrictions

Typed unary fetched leaf over supplied scalar state. Exact ISA94/SM>=20 feature condition on Step, even for disabled guards. No raw parsing, declaration or target-name validation, integer-to-float conversion, complete kernel execution or hardware conformance. Approximate, FTZ, other rounding modes and f64 forms remain unsupported.

Operands and execution

Destination
compatible b32/f32 word register
Sources
compatible b32/f32 word register or already-decoded exact 0f/0F bit literal
Overlap
Every source is read from the incoming state; source/destination overlap is unrestricted.
Guard
Unconditional, positive predicate or negated predicate; false guard preserves all data and advances PC, with guard-only read metadata.
Version
Introduced in PTX 2.0; selected ISA 9.4
Target
sm_20 feature floor; not target-name validation

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.
