9.7.3.21 · Restricted core model

ex2.approx.f32

Compute a base-two exponential in binary32 for nonpositive finite inputs, infinities and NaNs. Positive finite inputs are not yet modeled. Signed zeros return exactly positive one, negative infinity returns positive zero, positive infinity remains infinite, and NaNs remain NaNs. Strictly negative finite inputs retain every result in the declared union of center-based and output-based two-ULP allowances. ULP means the spacing of the floating-point grid.

Model restrictions

Partial input coverage: enabled positive finite operands have no step in this fragment; this is missing formalization, not PTX undefined behavior. A false predicate skips any operand. Exact PTX9.4, numeric SM>=20, no FTZ, typed words/literals, actual fetch and source/destination aliasing. The nearest-even reference and union of two ULP interpretations are explicit model choices; source fidelity and hardware realizability are separate. Not counted as an accepted full instruction form or a parallel softmax kernel.

This page documents an existing bounded formalization. It is not promoted to the independently accepted instruction-form ledger. Read its module comments and proof hypotheses for the precise execution restrictions.

def Results (input output : Word) : Prop :=
  (isNaN input = true ∧ isNaN output = true) ∨
  (input = 0xff800000 ∧ output = 0) ∨
  (input = 0x7f800000 ∧ output = 0x7f800000) ∨
  ∃ x : ℝ, finiteReal input = some x ∧ x ≤ 0 ∧
    if x = 0 then output = 0x3f800000 else ConservativeULP.Results ((2:ℝ)^x) output

private theorem finite_ne_infinities (input : Word) (x : ℝ)
    (value : finiteReal input = some x) : input ≠ 0xff800000 ∧ input ≠ 0x7f800000 := by
  constructor <;> intro h <;> subst input <;>
    rw [finiteReal_none _ (by decide)] at value <;> contradiction

/-- On a finite operand this characterizes every result, including exact zero. -/
