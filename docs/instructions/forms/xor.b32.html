9.7.9.3 · Reviewed form

xor.b32

Compare the two input words at each of their 32 bit positions. Set the corresponding result bit to one exactly when exactly one input bit is one; otherwise set it to zero. No carries or arithmetic rounding occur.

Model restrictions

Typed Pure32-family leaf over supplied scalar states with word sources and one word destination. No raw text/declaration checking, other widths, predicate-valued forms, complete kernel or hardware claim. Exact ISA94/SM>=10 feature requirement on fetched Step, not recognized-target validation.

Operands and execution

Destination
compatible 32-bit word register
Sources
compatible 32-bit word register or decoded immediate; compatible 32-bit word register or decoded immediate
Overlap
Incoming source values; unrestricted source/destination overlap and repeated operands.
Guard
Unconditional, positive or negative predicate; skipped execution advances PC and emits guard-only read metadata.
Version
Introduced in PTX 1.0; selected ISA 9.4
Target
sm_10 feature floor; not recognized-target validation

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.

Lean definitions

Ptx.Scalar.Bitwise32.compute · opening excerpt; follow the link for full source

def compute (op : Operation) (a b : Word) : Word :=
  match op with
  | .bitAnd => a &&& b
  | .bitOr => a ||| b
  | .bitXor => a ^^^ b
