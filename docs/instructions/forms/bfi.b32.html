9.7.1.21 · Reviewed form

bfi.b32

Use the low bits of the first source to replace a selected group of bits in the second source, the base word. Leave every other base bit unchanged.

Position and length each use only their low eight bits. Insertion stops at the highest bit of the 32-bit destination. A zero length or a starting position beyond that bit leaves the base unchanged.

Model restrictions

Typed Pure32 bfi.b32 family; ISA 94 and numeric SM >= 20. No bfi.b64, module parser, declared-register checking or hardware claim.

Operands and execution

Destination
compatible 32-bit word register
Sources
compatible declared 32-bit insertion source or already converted immediate; compatible declared 32-bit base source or already converted immediate; unsigned 32-bit position (low eight bits used); unsigned 32-bit length (low eight bits used)
Overlap
Incoming source values; unrestricted source/destination overlap and repeated operands.
Guard
Unconditional, positive or negative predicate; skipped execution advances PC and emits guard-only read metadata.
Version
Introduced in PTX 2.0; selected ISA 9.4
Target
sm_20 feature floor; not recognized-target validation

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.

def compute (_op : Operation) (a b c d : Word) : Word :=
  (BitVec.ofBoolListLE (List.ofFn fun (i : Fin 32) =>
    if c.toNat % 256 ≤ i.val ∧ i.val < c.toNat % 256 + d.toNat % 256 then
      a.getLsbD (i.val - c.toNat % 256) else b.getLsbD i.val)).cast (by simp)
