9.7.1.14 · Reviewed form

max.u32

Compare two 32-bit words as unsigned numbers from 0 through 2^32−1. Copy the larger value into the destination register. Equal inputs give that same value.

The signed form treats a set highest bit as part of a negative number; the unsigned form does not. Every input bit pattern is allowed.

Model restrictions

Typed operand interface only, not raw PTX parsing or register-declaration validation; version/target facts are not enforced by this arithmetic decoder. Exact values, not floating-point approximation or hardware conformance.

Operands and execution

Destination
u32 word register
Sources
u32 word register or 32-bit immediate; u32 word register or 32-bit immediate
Overlap
Sources read from incoming state before destination write; source/destination overlap permitted.
Guard
Unconditional, positive predicate, or negated predicate. False guard skips the write and advances the program counter.
Version
Introduced in PTX 1.0; this decoder does not enforce version/target eligibility
Target
all for selected forms

A word is a fixed-size sequence of bits. Signed and unsigned interpretations use the same bits but assign different numbers. A guard is a true-or-false condition deciding whether to execute. Immediate operands are values supplied directly. Typed operands have already been classified; this does not parse or validate a complete PTX module.

def BinOp.eval : BinOp → Word → Word → Word
  | .add, a, b => a + b
  | .sub, a, b => a - b
  | .mulLo, a, b => a * b
  | .and, a, b => a &&& b
  | .or, a, b => a ||| b
  | .xor, a, b => a ^^^ b
  | .shl, a, b => if b.toNat < 32 then a <<< b.toNat else 0
  | .shr, a, b => if b.toNat < 32 then a >>> b.toNat else 0
  | .minU, a, b => if a.toNat ≤ b.toNat then a else b
  | .maxU, a, b => if a.toNat ≥ b.toNat then a else b
