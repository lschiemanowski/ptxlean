9.7.10.11 · Restricted core model

st.relaxed.gpu.global.u32

Write a register word to an aligned location in the represented global-memory arena. Relaxed accesses alone do not synchronize communicating threads.

Model restrictions

This typed scalar frontend models an initialized, aligned whole-word arena, bounds checks and guard behavior. A separate memory-graph validity argument is needed for concurrent observations; an execution of the scalar evaluator alone is not PTX weak-memory admission.

This page documents an existing bounded formalization. It is not promoted to the independently accepted instruction-form ledger. Read its module comments and proof hypotheses for the precise execution restrictions.

Ptx.Scalar.eval · opening excerpt; follow the link for full source

def eval (readOverride : Option Word) (instruction : Instr) (s : State) : StepResult :=
  match instruction.op with
  | .unsupported spelling => .unsupported spelling
  | _ =>
      if instruction.guard.eval s then
        let advance := {s with pc := s.pc + 1}
        let event := occurrence s instruction true
        match instruction.op with
        | .mov32 destination source =>
            .next {advance with regs := update s.regs destination (source.eval s)} event
        | .bin32 operation destination left right =>
            .next {advance with regs := update s.regs destination (operation.eval (left.eval s) (right.eval s))} event
        | .unary32 operation destination source =>
            .next {advance with regs := update s.regs destination (operation.eval (source.eval s))} event
        | .mov64 destination source =>
            .next {advance with addrs := update s.addrs destination (source.eval s)} event
        | .add64 destination left right =>
            .next {advance with addrs := update s.addrs destination (left.eval s + right.eval s)} event
